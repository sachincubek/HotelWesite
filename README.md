# Shri Krishna Villa Homestay · Ujjain

A responsive, multi-page static website for Shri Krishna Villa Homestay. Built with semantic HTML, custom CSS, vanilla JavaScript and Bootstrap 5.

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server. For example:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Before publishing

- Replace all illustrative Unsplash images with approved property and destination photos; captions identify the placeholders.
- Update the contact fields (`phone`, `whatsapp`, and `email`) in `script.js` with verified details.
- Confirm room configurations, occupancy, amenities, policies, prices, exact map pin, and travel times with the property operator.
- Replace sample testimonials with real, permissioned guest feedback.
- The enquiry form currently validates in the browser only. It does not send, save, or confirm enquiries. Connect it to an approved backend or enquiry provider before relying on it.
- Review the starter privacy policy and terms against the operator’s actual practices.
